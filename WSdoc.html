AbstractWebSocketHandler Cheat Sheet

Method (Level + Return Type) When It Triggers Common Methods / Properties
protected void afterConnectionEstablished(WebSocketSession session) When a client successfully connects session.getId()
session.getRemoteAddress()
session.getAttributes()
protected void handleTextMessage(WebSocketSession session, TextMessage message) When a client sends text data (String / JSON) message.getPayload() → String
message.getPayloadLength()
protected void handleBinaryMessage(WebSocketSession session, BinaryMessage message) When a client sends raw bytes message.getPayload() → ByteBuffer
message.getPayload().array() → byte[]
protected void handlePongMessage(WebSocketSession session, PongMessage message) When a client responds to a ping message.getPayload() → ByteBuffer
protected void handleTransportError(WebSocketSession session, Throwable exception) When a network error or connection failure occurs exception.getMessage()
exception.getCause()
protected void afterConnectionClosed(WebSocketSession session, org.springframework.web.socket.CloseStatus status) When a client disconnects or times out status.getCode()
status.getReason()
public boolean supportsPartialMessages() Controls whether fragmented messages are supported Returns false by default
Tip: Most Spring WebSocket handlers override only: afterConnectionEstablished, handleTextMessage, afterConnectionClosed.
